## 🌟 ฟังก์ชันหลักที่อัปเกรดใหม่

### 1. 🇹🇭 แผนที่ความหนาแน่นคาร์บอน "ครอบคลุมทั่วประเทศ 100%" (เปิด/ปิดได้)
- แสดงแถบสีความหนาแน่นคาร์บอนแบบ **ตารางไร้รอยต่อ (Seamless Grid) ครอบคลุมครบทุกภาค ทุกจังหวัดในไทย**:
  - 🔴 **สีแดง (> 500 kg CO₂-eq/ไร่):** ลุ่มน้ำเจ้าพระยาตอนล่าง (อยุธยา-สุพรรณ-ชัยนาท) นาปรังขังน้ำตลอดปี
  - 🟠 **สีส้ม (450 - 540 kg):** ลุ่มน้ำยม-น่าน, เจ้าพระยาตอนบน, ลุ่มน้ำแม่กลอง
  - 🟡 **สีเหลือง (300 - 450 kg):** ภาคตะวันออก, อีสานตอนบน (ขอนแก่น-อุดรฯ), ภาคใต้
  - 🟢 **สีเขียว (< 300 kg):** ทุ่งกุลาร้องไห้ (ร้อยเอ็ด-สุรินทร์-อุบลฯ), แอ่งหุบเขาเชียงใหม่-เชียงราย นาน้ำฝนดินแห้งสลับธรรมชาติ
- มีปุ่มสวิตช์เปิด/ปิด `🔥 แผนที่คาร์บอน (เปิด/ปิด)` บนแถบเครื่องมือ
- ชี้เมาส์ที่ตารางตรงไหนของไทย จะขึ้นชื่อเขตและตัวเลขการปล่อยคาร์บอนเฉลี่ยทันที

### 2. 🛡️ ระบบตรวจจับความถูกต้องของแปลง (Land Validation AI)
- ❌ **ตรวจพบบ้านเรือน / ชุมชนหนาแน่น / อาคาร:** แสดงกล่องเตือนสีแดง `⚠️ ตรวจพบสิ่งปลูกสร้าง/บ้านเรือน (ไม่ใช่แปลงนา)` และระงับการคำนวณคาร์บอน
- ❌ **ตรวจพบแม่น้ำ / แหล่งน้ำธรรมชาติ:** แสดงกล่องเตือนสีน้ำเงิน `🌊 ตรวจพบแหล่งน้ำธรรมชาติ (ไม่ใช่แปลงนา)`
- ❌ **ขนาดเล็กเกินไป (< 50 ตร.ว.):** แสดงกล่องเตือน `⚠️ ขนาดเล็กเกินไปสำหรับแปลงนา`
- ✅ **ผ่านการตรวจสอบ:** แสดงแถบสีเขียว `✅ ตรวจสอบผ่าน: เป็นพื้นที่เกษตรกรรมนาข้าว`

### 3. 💨 คำนวณคาร์บอนมาตรฐานโลก (IPCC Tier-2 for Rice)
- ไม่ใช้ค่า NDVI หลอกตา แต่คำนวณจาก **ขนาดไร่จริง + สภาพอากาศจริง + การจัดการน้ำจริง**
- เปรียบเทียบระหว่าง:
  - **ขังน้ำต่อเนื่อง:** ปล่อยก๊าซมีเทนสูง (609 kg CO₂-eq/ไร่)
  - **เปียกสลับแห้ง (AWD):** ลดการปล่อยมีเทนทันที **48%** (เหลือ 317 kg CO₂-eq/ไร่)

### 4. 💰 เครื่องคำนวณเงินในกระเป๋า (Wealth & Savings Calculator)
- ค่าประหยัดน้ำมันวิดน้ำ (~750 บาท/ไร่)
- รายได้คาร์บอนเครดิต T-VER (600 บาท/ตัน CO₂-eq)
- โบนัสส่วนต่างราคาข้าวคาร์บอนต่ำ (+400 บาท/ตันข้าวเปลือก)

### 5. 🌤️ พยากรณ์อากาศ 7 วันจริง & เรดาร์เตือนภัย
- ข้อมูลอุณหภูมิ, ฝนสะสม, ความชื้น, แสงแดด สดจากดาวเทียมตรวจอากาศ
- เรดาร์เตือนโรคไหม้คอรวง, พายุฝน, คลื่นความร้อน
